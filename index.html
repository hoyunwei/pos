看這頁就會收銀了，照著做就好，不用緊張 🙂

① 賣一筆東西（最常用）

  1. 在「收銀台」點左邊的商品 → 會自動加進右邊購物車
  2. 數量不對，就在購物車那筆按 ＋ / − 調整
  3. 按「現金結帳」或「LINE Pay」
  4. 收錢、找錢 → 完成，庫存會自動扣掉

② 優惠系統會自動算，你不用心算 🎉

東西加進購物車，符合的優惠會自動跳出來並扣好金額，購物車下方會寫「套用了什麼優惠、折了多少」，可以直接唸給客人聽。

  • 紙品任選 3 件 8 折：明信片、凸版明信片、細長海報、A4 海報、凸版方形，可以混搭湊件
  • 水晶貼任選 3 片 8 折：大中小可以互相湊
  • 貼紙 3 張 $50（原價 60）
  • L 夾 2 個 $180（原價 200）
  • 冰箱貼不打折，維持原價

湊不滿一組的餘數自動算原價，折扣一定套在比較貴的那幾件，對客人最有利。

③ 書籤：滿額送 ／ $29 加購

  • 應收滿 $300 → 購物車跳綠色提示「可送書籤 1 張」，真的拿給客人後再按「已送出」（庫存才會扣對）
  • 還沒滿 $300 會顯示「再 $XX 就送書籤」→ 可以直接拿來跟客人湊單
  • 客人想多要書籤：按「＋ $29 加購透卡書籤」，按幾次就幾張
  • 加購的 $29 不算進滿 $300 的門檻

④ 收款怎麼收

  • 現金：在欄位輸入客人給的金額，系統會自動算「要找多少」
  • LINE Pay：請客人掃碼，確認到帳後再按完成

⑤ 按錯、算錯怎麼救

別慌，可以改！

  1. 點上方「日結報表」
  2. 找到那筆訂單，點它
  3. 可以改數量、刪某個品項、或整筆刪掉
  4. 改完庫存會自動還原，不會算錯

⑥ ⚠️ 這些請不要碰

  • 不要進「商品管理」改商品、價格、庫存
  • 不要按「匯入 / 匯出 JSON」
  • 不要用無痕視窗、不要清除瀏覽器資料（資料會不見！）
  • 遇到解決不了的狀況 → 直接問小何

⑦ 開攤 / 收攤檢查

  • 開攤前：確認商品都在、價格正確
  • 收攤後：到商品管理按「匯出全部備份 JSON」存一份，以防萬一
